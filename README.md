# Atharva Ortho Care Website

Premium static orthopaedic website for Dr. Ajeya Deshpande.

## Included
- Home, About Doctor, Specialities, Patient Reviews, Media & Gallery, Contact, Book Appointment
- Client doctor photo wired in
- Placeholder gallery and testimonial areas clearly marked for later replacement
- Appointment form with validation and confirmation message
- Floating WhatsApp button and mobile action bar

## Notes
- No database, login, admin panel, React, WordPress, or CMS
- Review content is intentionally placeholder-only until approved client testimonials are supplied
- Gallery images are intentionally placeholder-only until final photos are supplied
